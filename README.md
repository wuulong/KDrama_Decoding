# 《韓劇羅曼史解讀手冊》：從感性體驗到文明認知的轉化指南

**（K-Drama Romance Decoding: A Post-Viewing Guide to Civilizational Insight）**

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Version](https://img.shields.io/badge/Version-1.0-green.svg)

這是一本關於「如何看懂韓劇」的文明工具書。它不教你如何追星，而是教你如何透過 AI 的賦能，拆解韓劇背後的語言階級、社會操作系統、以及隱藏在羅曼史糖衣下的文明密碼。

## 📖 本書核心價值
- **跨越文化門檻**：解析敬語、平語、儒家契約與財閥邏輯，補足非韓語母語者的認知缺口。
- **知識資產化**：展示如何利用 AI 將觀影的「感性體驗」轉化為「理性能量」，並沉澱為結構化的知識資產。
- **文明對位**：將韓劇的角色原型（如洪班長）與現實中的生命實踐（如開放社群精神）進行深度連結。
