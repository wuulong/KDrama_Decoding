# KDrama Civilizational Decoder Skill

此技能專用於在使用者「完看完畢」一部韓劇後，提供一套通用的解析框架，將單純的觀影心得昇華為文明層次的洞察。

## 1. 核心解析維度 (The Four Dimensions)

當使用者啟動解析（例如輸入：我剛看完了《XXX》，開始解碼）時，技能應從以下四個維度引導對話：

### A. 社會操作系統 (Social OS Scanner)
- **語言階級**：敬語/平語的轉折、權力壓制或情感突破。
- **階級圖騰**：學歷（如首爾大）、職位、居住地（如江南區）在劇中的權威性。
- **共同體邏輯**：該劇是基於「我們 (Uri)」的集體邏輯，還是現代個體的契約邏輯？

### B. 空間與時間邏輯 (Spatial-Temporal Logic)
- **時空設定**：都市（線性、競爭）vs 地方（循環、療癒）。
- **邊界演進**：角色如何從一個空間跨越到另一個空間？空間如何改變其價值觀？

### C. 符號與隱喻 (Symbolic Harvesting)
- **物件隱喻**：識別劇中反覆出現的象徵物（如：雨傘、鞋子、特定食物、交通工具）。
- **自然元素**：雨、海、風、土地在情感表達中的功能。

### D. 心理與傷痕原型 (Psychological Archetypes)
- **傷痕解析**：角色背負的「倖存者愧疚」或原生家庭創傷。
- **依附演進**：角色如何從防禦型依附走向安全依附？
- **對合驗證**：區分編劇的社會觀察與純粹的戲劇加工。

## 2. 執行流程 (Execution Flow)

1. **感性觸發**：詢問使用者全劇中最受觸動、或最感到「不合理/看不懂」的一幕。
2. **多層掃描**：從上述四個維度選取 1-2 個最相關的切入點進行深度拆解。
3. **跨劇對照**：將本劇與使用者過去看過的劇（如《海岸村》、《淚的女王》）進行邏輯連結，形成連續的知識網。
4. **價值遷移**：探討本劇的文明邏輯，是否能反饋到使用者其他的實踐領域（如河流探索、社會研究）。

## 3. 注意事項
- **不強制存檔**：除非使用者要求，否則不主動調用 `aiqa-scribe` 或其他存檔技能。
- **尊重感性**：解析應建立在使用者真實的觀影體感之上，不進行空洞的理論說教。
- **通用性**：不論是現代愛情、時代劇或職場劇，皆應嘗試套用此通用框架。
